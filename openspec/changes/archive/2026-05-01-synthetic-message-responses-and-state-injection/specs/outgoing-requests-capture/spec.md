## MODIFIED Requirements

### Requirement: Canned responses accept static values OR functions

The system SHALL resolve each outgoing API call against the configured `responses` map (keyed by method name). Each entry SHALL be either a static `Partial<Result<M>>` value or an async function `(payload, method) => Partial<Result<M>>`. When an entry is present, the static value or function's return value SHALL be wrapped in `{ ok: true, result }` and returned. User-supplied `responses` entries SHALL take precedence over any default responses generated by the library.

For message-sending methods (`sendMessage`, `sendPhoto`, `sendDocument`, `sendVideo`, `sendAudio`, `sendVoice`, `sendVideoNote`, `sendAnimation`, `sendSticker`, `sendLocation`, `sendContact`, `sendVenue`, `sendPoll`, `sendDice`, `sendMediaGroup`), the library SHALL supply a default response when no user entry is present (see the `synthetic-message-responses` capability). For all other methods, the fallback remains `{ ok: true, result: true }`.

#### Scenario: Static canned response is returned as-is

- **WHEN** `responses: { getChat: { id: 1, type: "private" } }` is configured
- **AND** the bot calls `ctx.api.getChat(123)`
- **THEN** the resolved result equals `{ id: 1, type: "private" }`

#### Scenario: Function resolver receives payload and method

- **WHEN** `responses: { sendMessage: (payload) => ({ message_id: payload.chat_id + 1 }) }` is configured
- **AND** the bot calls `ctx.reply("hi")` in a chat with id `100`
- **THEN** the resolved `message_id` equals `101`

#### Scenario: User-supplied sendMessage response overrides the synthetic default

- **WHEN** `responses: { sendMessage: { message_id: 9999, date: 0 } }` is configured
- **AND** the bot calls `ctx.reply("hello")`
- **THEN** the resolved `message_id` equals `9999`

#### Scenario: Non-message methods without an entry still resolve to true

- **WHEN** no `responses.deleteMessage` entry is configured
- **AND** the bot calls `ctx.api.deleteMessage(chatId, msgId)`
- **THEN** the resolved result equals `true`
